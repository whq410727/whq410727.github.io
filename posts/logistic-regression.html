用 statsmodels 做逻辑回归：从数据到结论

2026-10-05 数据分析

逻辑回归是数据分析中最常用的分类模型之一。本文以一份二分类数据集为例，记录使用 statsmodels 完成逻辑回归分析的完整流程。

一、准备工作

import pandas as pd
import statsmodels.api as sm
from sklearn.model_selection import train_test_split

# 读取数据
df = pd.read_csv("data.csv")
print(df.columns)

二、数据预处理

假设因变量为 y（0/1），自变量为若干列。需要注意：

  • 分类变量需做独热编码（get_dummies）
  • 缺失值需提前处理
  • statsmodels 不会自动加截距项，需手动添加
# 划分特征与标签
X = df.drop("y", axis=1)
y = df["y"]

# 添加截距项
X = sm.add_constant(X)

# 划分训练集测试集
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42
)

三、构建模型

model = sm.Logit(y_train, X_train)
result = model.fit()
print(result.summary())

四、结果解读

summary() 输出中重点关注：

  • coef：回归系数，取指数后为优势比（OR）
  • P>|z|：p 值，小于 0.05 表示显著
  • Pseudo R-squared：模型拟合优度
# 计算优势比
import numpy as np
odds_ratios = np.exp(result.params)
print(odds_ratios)

五、模型评估

from sklearn.metrics import accuracy_score, roc_auc_score

# 预测
y_pred = (result.predict(X_test) > 0.5).astype(int)
y_prob = result.predict(X_test)

print("准确率:", accuracy_score(y_test, y_pred))
print("AUC:", roc_auc_score(y_test, y_prob))
经验：AUC 在 0.7-0.8 之间说明模型有一定区分能力，0.8 以上较好。
